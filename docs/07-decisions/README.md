## Règle de statut

Les ADR déjà listés sont des orientations de conception à confirmer, sauf mention explicite d'une validation du propriétaire. La présente phase ne ferme pas les questions dépendant de l'audit REA.

## Ajouter ou modifier une décision

Documenter contexte, décision, statut (`proposé`, `accepté`, `remplacé`), alternatives, conséquences et dépendances. Une décision structurante déjà acceptée est remplacée par un nouvel ADR qui référence l'ancien ; ne pas effacer l'historique.
